00这份页面回答什么

一句话：在完全没有信号的数据上，这套「不会撒谎」的流程会报出多少次「显著」？

要审的是流程，不是 agent。「从一堆配置里挑最好的再报数」这个动作本身， 在零信号数据上会把虚报率从名义 0.05 抬到 0.525（budget=24，40 次里 21 次报「显著」）。 偏差主要来自「挑」这个动作，而非「会推理的智能体」——纯随机抽样同样能到 0.55。

冻结基线：两次为同一 handle

服务端 eeg_ablation 的 bandpower+LDA 基线两次均给出 eval_97c24b8b38c1 = 0.5667，分毫不差。 同一份数据、同一套代码，内容寻址产物逐字节相同。

漂移不是数据或工具造成的

冻结基线同一 handle；第三幕两档 40 个 handle 也逐一致复现。

漂移出在 agent 的预处理选择

换一个预处理旋钮，主结论可以差 ~0.03，而这不是「谁对谁错」，是「挑哪个」的问题。

两次的置换 p 都是 0.0323、都「显著」，但两次对应的观测值并不相同（0.6078 / 0.5815） ——同一个「显著」标签，底下是两个不同的数。这与第二幕的毛病同源：报告的主数字依赖一个事后选定的配置。
