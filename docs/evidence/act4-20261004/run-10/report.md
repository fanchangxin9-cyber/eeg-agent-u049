> 原始事件段：270 段 × 64 通道 × 673 时间步 @ 160 Hz（窗口 −0.2 s 至 4.0 s）

## 二、方法

### 最终配置

| 参数 | 值 |
|---|---|
| 预处理 | 8–30 Hz 带通、50 Hz 陷波、150 µV 伪迹剔除、crop [1.0, 3.0] s、全通道、无共平均参考 |
| 特征 | bandpower+asymmetry（mu、beta 频段），按被试 z-score 归一化 |
| 模型 | LDA |
| 交叉验证 | 5 折，within_subject（每被试内部 5 折分层，再按被试汇总） |
| 评估指标 | 平衡准确率（chance = 0.5）、Cohen's κ、混淆矩阵 |

### 为什么这样选（决策日志摘要）

| # | 观察 | 决定 | 理由 |
|---|---|---|---|
| 1 | bandpower+LDA within_subject 平衡准确率 0.486（C1），接近随机 | 试 CSP | CSP 预期增益最大 |
| 2 | CSP+LDA 0.4818（C1, eval_8f6d860f68d0），未提升 | 试收窄窗口 [0.5, 3.5] s | 判别信息集中在提示后 0.5–3.5 s |
| 3 | CSP+crop[0.5,3.5] 0.4863（C1, eval_2bfba0588ff3），未提升 | 试更短窗口 [1.0, 3.0] s | ERP 核心期 |
| 4 | CSP+crop[1.0,3.0] 0.4841（C1, eval_18f260f7309a），折间 std 0.111 偏大 | 换 asymmetry 特征 | 左右手 C3/C4 对侧偏侧化有明确生理依据 |
| 5 | bandpower+asymmetry+LDA **0.5316**（C1, eval_d14e5eaa526a），kappa 0.0746 | 试 SVM | 利用非线性判别 |
| 6 | SVM 0.4926（C1, eval_704ec7292bc3），反而变差 | 停止 | 连续 3 组无提升 > 1 pp |

> 注：CSP 在本数据集上未达参考值 0.63，可能与被试集合或数据版本有关，如实报告。

## 三、结果

### 3.1 最佳配置（within_subject）

**协议：within_subject（每被试内部 5 折分层，再按被试汇总）**

| 平衡准确率 | **0.5316** |
| 平衡准确率 std | 0.0797 |
| 准确率 | 0.5373 |
| F1 macro | 0.5372 |
| Cohen's κ | 0.0746 |
| 混淆矩阵 | [[67, 61], [57, 70]] |
| 事件段数 | 255 |
| 被试数 | 6 |

按被试（within_subject）：被试 1 = 0.6333，被试 2 = 0.5109，被试 3 = 0.4668，
被试 4 = 0.5042，被试 5 = 0.6429，被试 6 = 0.4317（std 0.0797）。

### 3.2 跨被试协议（cross_subject）

**协议：cross_subject（GroupKFold(5) 按被试分组）**

| 配置 | 平衡准确率 | std | κ |
|---|---|---|---|
| bandpower+asymmetry + LDA | **0.5225** | 0.0649 | 0.0665 |
| CSP + LDA | **0.4738** | 0.0370 | −0.0434 |

cross_subject 平衡准确率 0.5225（bandpower+asymmetry）略高于随机（0.5），
但 CSP cross_subject 仅 0.4738，接近随机。跨被试泛化能力有限，
与文献中小被试集上的已知现象一致。

## 四、验证

### 4.1 置换检验（shuffle control）

**协议：within_subject，5 折，与主评估一致**

- 分 3 批各 10 次置换（seed = 1 / 2 / 3），再合并为 30 次
- 观测平衡准确率：0.5316
- 合并后 null 分布：mean = 0.4935，std = 0.0415，p95 = 0.5614，max = 0.5939
- **p = 0.1290**（30 次置换，理论下限 1/31 ≈ 0.0323）

各批单独 p 值：seed 1 → p = 0.1818；seed 2 → p = 0.0909；seed 3 → p = 0.2727。

**结论：未显著高于随机水平（p > 0.05）。**
该配置未能通过置换检验证明学到真实判别信息。

### 4.2 留出被试验证（holdout subject）

**协议：train = 被试 1–3，test = 被试 4–6（测试被试未参与任何拟合步骤）**

| 指标 | 值 |
|---|---|
| 平衡准确率 | 0.4959 |
| 准确率 | 0.4961 |
| F1 macro | 0.4958 |
| Cohen's κ | −0.0082 |
| 测试事件段 | 127 |
| 训练事件段 | 128 |

留出被试结果接近随机水平，与 cross_subject 协议结论一致。

## 六、局限

1. **被试数仅 6 人**，每被试 45 段，统计检验力有限；置换检验 p 值下限为
   1/31 ≈ 0.0323，真实效应若接近阈值可能被误判为不显著。
2. **个体差异显著**：within_subject 各被试准确率从 0.4317 到 0.6429 不等
   （std 0.0797），被试 6 明显弱于被试 5。
3. **置换检验未达显著**（p = 0.1290）：0.5316 的平衡准确率在 30 次置换下
   未显著高于 null 分布（max = 0.5939），说明该效应可能部分是流程噪声。
4. **跨被试泛化能力弱**：cross_subject 平衡准确率 0.5225（asymmetry）和
   0.4738（CSP）均接近随机，留出被试 4–6 仅 0.4959。
5. **CSP 未达参考值**：本数据集上 CSP within_subject 仅 0.4818，低于 skill
   参考值 0.63，可能与被试集合或数据版本有关，未能复现预期增益。
6. **多重比较问题**：试了 6 组配置，最终选出的 0.5316 在某种程度上是
   "搜索后最优"，存在多重性偏差。
7. **基线对比中 same_epoch_set = false**：两组样本量不同（270 vs 255），
   Δ 中混入预处理贡献，不能单纯归因于特征方案。
