# EEG 运动想象解码分析报告

> 参赛演示 · 第一幕
> 数据集：EEGMMIDB v1.0.0（PhysioNet，ODC-BY 1.0）· 任务：left_vs_right_imagery（想象左手 vs 想象右手）
> 本报告由 EEG 分析 agent 在 MCP 工具链上运行生成；每个数字均可溯源到 `eeg_evidence` 的 claims（溯源 handle 已在文内标注）。

## 1. 数据概况

- 来源：EEGMMIDB v1.0.0，被试 1–6，runs 4/8/12，任务 `left_vs_right_imagery`（运动想象）。
- 加载后：270 个 epoch，64 通道，160 Hz，单 epoch 时长 4.206 s（加载窗口 -0.2–4.0 s）。
- 类别分布：left_fist 137 / right_fist 133，基本平衡；每被试 45 epoch。
- 质量诊断：无幅值异常（median_abs 22 µV，p99_abs 167 µV，max_abs 639 µV），无平坦通道，无告警，`healthy=true`。
- 预处理后（最终配置）：255 epoch（剔除 15，占比 5.6%）；被试 4 剔除率 15.6% 偏高但未排除（剩余样本仍充足）。

## 2. 方法

**最终配置**：8–30 Hz 带通 + 150 µV 伪迹阈值 + 分析窗口 [1.0, 3.0] s + 全通道 + 原始参考（reref=none），CSP 空间滤波 + LDA 分类器。

**交叉验证协议（两条都跑，分别报告）**：
- `within_subject`：每被试内部 5 折分层，再按被试汇总——对应真实 BCI 的逐人标定场景，是本报告的主指标。
- `cross_subject`：GroupKFold(5) 按被试分组，测试被试完全不参与训练——衡量无标定泛化，是公认难题。

**为什么这样选（决策日志摘要，每轮「观察 → 决定 → 理由 → 下一步」）**：

1. 观察：诊断干净，类别平衡。决定：不剔道、不用 CAR（CAR 实测有害）、先建 bandpower 锚点。理由：先量化 CSP 相对手工频带功率的增益。
   → bandpower+asymmetry(mu/beta) + LDA，被试内：**0.4826**（±0.0878，kappa -0.0352）`eval_1353033738d5`。
2. 观察：锚点接近随机。决定：升级 CSP（影响最大的旋钮）。理由：CSP 学出对运动区对侧偏侧化最敏感的空间投影。
   → CSP+LDA+[0.5,3.5]，被试内：**0.4875**（±0.089）`eval_74e87a3589dd`。
3. 观察：CSP 仍低，被试 6 只有 0.329。决定：缩短窗口到 [1.0,3.0]，去掉 3.5 s 尾端放松段。理由：ERD/ERS 判别信息集中在提示后 1–3 s。
   → CSP+LDA+[1.0,3.0]，被试内：**0.5098**（±0.0746）`eval_6b92b9ebe0d0` —— 当前最佳。
4. 观察：三组窗口对比 [0.5,3.5]→0.4875、[1.0,3.0]→0.5098、[0.5,3.0]→0.4654（`eval_1d3bffc628ec`），[1.0,3.0] 最优。决定：固定 [1.0,3.0] 试 SVM。
   → SVM+CSP：0.4894（`eval_1d34b337e6b8`），略差；再试 logreg+CSP：0.4672（`eval_f80d6a687bba`），更差。LDA 胜出。
5. 停止准则：「最多 6 组配置；连续 3 组无 >1 个百分点提升即停」。组 3→4→5 停在 0.465–0.510 区间，触发停止，定 CSP+LDA+[1.0,3.0] 为最终配置。

**未采纳的标准做法及实测理由**（反直觉结论，如实记录）：
- CAR 共平均参考：实测有害，CSP 会自行学最优空间权重，手动重参考反而冲突 → 不采用。
- 只选运动区通道：实测基本无变化（CSP 即空间滤波器）→ 不采用。
- 加 theta 频段：被试数增多后反而不稳定 → 不采用。

## 3. 结果

**被试内协议（within_subject，5 折，随机水平 0.5）** —— 最终配置 CSP+LDA+[1.0,3.0]：
- 平衡准确率 **0.5098**（±0.0746），accuracy 0.5137，F1-macro 0.5134，Cohen's kappa **0.0277** `eval_6b92b9ebe0d0`。
- 混淆矩阵：[[62,66],[58,69]]。
- 分被试：S1 0.5619 / S2 0.4437 / S3 0.4023 / S4 0.4694 / S5 0.5893 / S6 0.5921，std 0.0746。

**跨被试协议（cross_subject，GroupKFold 5 折）** —— 同一最终配置：
- 平衡准确率 **0.5104**（±0.0133），accuracy 0.4954，F1-macro 0.3674，kappa 0.003 `eval_f5a76b00142a`。
- 混淆矩阵：[[79,49],[78,49]]；各折平衡准确率 0.50 / 0.499 / 0.50 / 0.5227 / 0.5302，紧贴随机水平。
- **两种协议的差异及原因**：被试内略高是符合预期的——训练与测试同被试，CSP 在每折内对该人单独拟合，吸收了个体幅度/空间模式差异；跨被试协议测试被试完全未见，小被试集（n=6）上 CSP 学到的空间滤波器无法迁移，结果退回随机。跨被试接近随机是已知现象，如实报告而非藏起。

## 4. 验证

**置换检验（打乱标签重跑同一套交叉验证，排除流程泄漏）**：
- 观测值 0.5098 未超过打乱分布尾（3 批各 10 次，seed 1/2/3，模型/协议/折数一致，合并共 30 次置换 `eval_aa523dd313e9`）：
  - 批 1（seed 1）p = 0.3636，批 2（seed 2）p = 0.7273，批 3（seed 3）p = 0.2727；
  - **合并 30 次：p = 0.4194**。
- 判读：p ≫ 0.05，且观测值落在打乱分布内部（打乱均值 0.4914，p95 0.5382），**未显著高于随机水平**——即当前配置下的 0.51 不能确证学到了真实判别信息，不能包装成"有效"结果。
- p 值说明：单批 10 次置换 p 的理论下限为 1/(10+1)=0.0909，次数不足会把真实效应误判为不显著；按 skill 办法分 3 批各 10 次（不同 seed）再合并到 30 次，把 p 值下限提到 1/31≈0.0323。即便下限提高后 p 仍为 0.4194，不显著是实质性的。

**留出被试验证（holdout_subject，测试被试 4 完全不参与任何拟合）**：
- 平衡准确率 **0.5**（= 随机水平），accuracy 0.5263，F1-macro 0.3448，kappa 0.0；38 个测试 epoch，217 个训练 epoch `eval_54a369c11e6f`。
- 判读：与跨被试结论一致——无标定泛化未能超过随机。

## 5. 与基线对比

冻结基线（bandpower+mu/beta+LDA，被试内，5 折，无伪迹剔除，窗口 [0.5,3.5]）：
- 基线平衡准确率 **0.3952**（±0.0776）`eval_51a9b5516c89`。
- 最终配置 **0.5098**，**delta = +0.1146**，服务端判定 verdict = **agent_config_better**。
- 增益来源（设计意图，已如实声明）：① CSP 替代手工频带功率（影响最大）；② 窗口收窄到 [1.0,3.0]；③ 加 150 µV 伪迹剔除（改变了样本集合 270→255，`same_epoch_set=false`，故差异中同时含预处理贡献，不能全部归因于 CSP 一项）。

## 6. 局限

- **被试数 n=6**：分组交叉验证与跨被试结论都不稳定，单次 fold 的平衡准确率波动大（被试内 ±0.0746）。
- **个体差异大**：被试内分被试准确率从 0.4023（S3）到 0.5921（S6）跨度近 19 个百分点，平均数掩盖了"部分被试接近随机"的事实。
- **未超过随机水平（置换 p=0.4194）**：严格意义上，本次 0.51 的被试内结果**不能排除是流程或数据固有的偶然性**；与基线的 +0.1146 增益是在"未通过置换显著性"的前提下观察到的，引用时须注明。
- **跨被试泛化失败**（0.5104，留出被试 4 = 0.5）：无标定场景下 CSP 不可迁移，与 BCI 领域已知结论一致，但意味着本结果不能宣称可泛化到新使用者。
- **多重比较**：搜索过 6 组配置（3 个窗口 × 3 种分类器 + bandpower 锚点 + 跨被试重复），在多个候选中挑最优再检验会抬高假阳性风险；报告按"最优配置"汇报而非族级最优。
- **未做的事**：未调 CSP 成分数、未试 SVM 核参数、未对被试 4 的高剔除率（15.6%）做针对性处理、未跑 6 被试以上的大样本。
- 合规说明：本报告输出仅为信号分析参考，**不构成医疗诊断**。
