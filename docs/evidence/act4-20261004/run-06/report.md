# EEG 运动想象解码分析报告

> 本报告中所有数值均来自 `eeg_evidence` 的 claims，未列出的数字未写入。
> 数据集：EEGMMIDB v1.0.0（PhysioNet），6 名被试，运动想象左右手任务。

---

| 被试数 | 6（被试 1–6） |

## 二、方法

### 最终配置

| 参数 | 值 |
|---|---|
| 预处理 | 带通 8–30 Hz；裁剪 [1.0, 3.0] s；伪迹剔除 reject_uv=150 |
| 特征 | CSP（Common Spatial Patterns） |
| 分类器 | LDA |
| 交叉验证 | 5 折分层 |
| 评估协议 | within_subject（每被试内部 5 折，再按被试汇总） |
| 输入样本数 | 255（剔除 15 个极端试次后） |

### 为什么这样选（决策日志）

**轮次 1：bandpower + LDA + within_subject（crop [0.5, 3.5]，reject_uv=150）**
- 观察：平衡准确率 0.4893（claim C1 of eval_991fb7a67e3d），接近随机 0.5；cohen_kappa = -0.0203
- 决定：切换到 CSP 特征
- 理由：bandpower 只提取频段功率，判别力有限；CSP 是空间滤波器，能学到对分类最有用的空间权重，搜索空间中影响最大的旋钮（实测参考：0.55 → 0.63）
- 下一步：对 clean 产物直接跑 CSP + LDA + within_subject

**轮次 2：CSP + LDA + within_subject（crop [0.5, 3.5]，reject_uv=150）**
- 观察：平衡准确率 0.4671（claim C1 of eval_9baf54888108），比 bandpower 还低
- 决定：收窄分析窗口至 [1.0, 3.0] s
- 理由：crop [0.5, 3.5] 包含较多静息段，CSP 在宽窗口下维度多容易过拟合；[1.0, 3.0] 聚焦运动想象核心时段
- 下一步：预处理 crop_sec=[1.0, 3.0]，再跑 CSP + LDA + within_subject

**轮次 3：CSP + LDA + within_subject（crop [1.0, 3.0]，reject_uv=150）**
- 观察：平衡准确率 **0.5435**（claim C1 of eval_2b481e08f1f6），std = 0.1002，cohen_kappa = 0.089
- 决定：固定此窗口为最终配置，不再继续搜索
- 理由：0.5435 是当前最高值；后续两组窗口（[0.8, 2.8] → 0.5124，[1.0, 3.5] → 0.5254）均低于 0.5435，连续两组无 >1 个百分点提升，触发停止准则

各被试（作为测试被试时）平衡准确率：

- 被试 4：0.4474；被试 5：0.6；被试 6：0.6364

**解读**：跨被试协议下 0.5575 也高于随机 0.5，说明 CSP 学到的空间方向有一定跨被试泛化能力（幅度有限，kappa=0.1003）。跨被试接近随机是已知现象，0.5575 在此规模下已属可接受。

### 两种协议差异原因

within_subject（0.5435）与 cross_subject（0.5575）数值接近，但回答的问题不同：
- within_subject 衡量"在该使用者身上能否解出运动想象"（BCI 标准标定场景）
- cross_subject 衡量"能否不做标定就套用到新使用者"（公认的难题）
- 跨被试略高可能是 6 名被试样本量小、随机波动所致，不应过度解读

## 四、验证

### 置换检验（shuffle_control，30 次）

- 方案：CSP + LDA + within_subject + 5 折，分 3 批各 10 次置换（seed=1, 2, 3），合并
- 观测值：0.5435
- 打乱分布均值：0.4956；标准差：0.0363；p95：0.5455；max：0.563
- **p 值：0.0968**（30 次置换的理论下限为 1/31 ≈ 0.0323）
- 来源：eval_48666b88dadd

**解读**：p = 0.0968 > 0.05，在 30 次置换下未达到统计显著。观测值 0.5435 落在打乱分布的 p95（0.5455）附近，说明当前效果可能存在但强度有限，不能排除是随机波动。若需更强结论，需增加置换次数（如 100 次），但受 CSP 计算耗时限制。

### 留出被试验证（holdout_subject）

- 测试被试：6（44 个试次）；训练被试：1–5（211 个试次）
- 平衡准确率：**0.6418**；cohen_kappa = 0.2802
- 来源：eval_852393771b9f

**解读**：留出被试 6 的独立验证达到 0.6418，显著高于 within_subject 均值 0.5435，说明 CSP 在该被试上的判别力较强。但 44 个试次的样本量较小，置信区间宽，单被试结果不宜过度外推。

## 六、局限

1. **被试数仅 6 名**：分组交叉验证（cross_subject）在 6 被试上不稳定，折间标准差大，单被试结果波动明显。
2. **个体差异大**：within_subject 下各被试准确率从 0.4226 到 0.7143，标准差 0.1002，说明模型对不同被试的适用性不一致。
3. **置换检验未达显著**：30 次置换 p=0.0968 > 0.05，当前证据不足以排除随机波动；若需更强结论需更多置换次数（受计算资源限制）。
4. **cross_subject 协议**：跨被试 0.5575 接近随机，说明泛化能力有限；这是已知难题，不代表方法失败，但不应作为主要结果。
5. **伪迹剔除改变了样本集合**：基线 270 epochs vs agent 255 epochs，对比中 `same_epoch_set = false`，增益中混入预处理贡献。
6. **未做的事**：未尝试 SVM/LogReg 模型、未尝试带通 8–30 Hz 以外的频段（如加 gamma）、未做 CAR 重参考（实测有害，已跳过）、未做多组比较（CSP 维度数等超参数）。
7. **本工具输出仅为信号分析参考，不构成医疗诊断。**
