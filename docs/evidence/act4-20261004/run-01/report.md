# EEG 运动想象解码分析：EEGMMIDB 被试 1–6（左手 vs 右手想象）

> 本报告中所有数字均来自 `eeg_evidence` 收集的可引用 claims（C1–C13）；验证数字
> （p 值、置换分布）取自 `eeg_validate` 与 `eeg_ablation` 的服务端计算结论。
> 报告明确标注每条结果所属的交叉验证协议。

---

## 1. 数据概况

| 项目 | 数值 |
|---|---|
| 数据集 | EEGMMIDB v1.0.0（PhysioNet，ODC-BY 1.0） |
| 任务 | 运动想象（left vs right） |
| 被试 | 6 名（编号 1–6） |
| 运行次数 | 4、8、12 次 |
| 事件段总数 | 270 段（每被试 45 段） |
| 通道数 | 64 通道 |
| 采样率 | 160 Hz |
| 时段 | 4.206 秒（加载窗口 -0.2–4.0 秒） |
| 类别 | left 137 段 vs right 133 段（基本平衡） |
| 伪迹剔除后样本数 | 251 段（剔除 19 段，7.0%） |

所有 6 名被试均成功加载，无缺失被试。

---

## 2. 方法

### 2.1 预处理

| 参数 | 取值 | 理由 |
|---|---|---|
| 带通滤波 | 8–30 Hz | 覆盖 mu（8–13）+ beta（13–30）频段，是运动想象 ERD 所在区间 |
| 分析窗口 | 0.5–3.5 秒 | 提示后 0.5 秒跳过运动诱发电位（MEP），3.5 秒捕捉运动后去同步（MRD） |
| 伪迹阈值 | 150 μV | 数据 p99=167、max=639，150 可剔除大量极端段而不损失有效数据 |
| 通道选择 | 全 64 通道 | CSP 本身是空间滤波器，手动选道实测无用 |
| 重参考 | 不重参考（none） | CAR 实测有害（0.552→0.528），CSP 已学出最优空间权重 |
| 陷波 | 无 | 数据中未检测到明显 50/60 Hz 工频干扰 |

### 2.2 特征方案

- **带功率（bandpower）**：mu + beta 两频段 × 64 通道 = 128 维
- **归一化**：按被试 z-score（subject normalization）

选择理由：bandpower 是被试内协议的标准做法，实测 0.56，比 CSP（本数据上 0.51）稳定。

### 2.3 分类器

线性判别分析（LDA），不启用 CSP。

### 2.4 交叉验证协议

- **被试内（within_subject）**：每被试内部 5 折分层，再按被试汇总。
  回答「在该使用者身上能否解出运动想象」，对应 BCI 的逐人标定场景。
- **跨被试（cross_subject）**：按被试分组，测试被试完全不参与训练。
  回答「能否不做标定就套用到新使用者」，是公认难题，预期接近随机。

两种协议分别独立报告。

### 2.5 独立验证（置换检验）

- 方案：shuffle_control，分 3 批 × 10 次置换（seed = 0, 1, 2），合并共 30 次。
- 各批协议一致：LDA + bandpower + within_subject + 5 折。
- p 值解读：p = 1 / (n_perm + 1)，30 次置换下若观测值超过全部打乱结果，p = 0.0323。

## 3. 结果

### 3.1 被试内协议（within_subject）

| 配置 | 平衡准确率（均值） | 标准差 | Cohen's κ | 备注 |
|---|---|---|---|---|
| bandpower + LDA（**最终配置**） | **0.5605**（C1） | 0.0627（C2） | 0.124 | 显著优于随机 |
| bandpower + LDA（crop [0,3]） | 0.5600 | 0.0614 | 0.119 | 与 [0.5,3.5] 基本持平 |
| CSP + LDA（crop [0.5,3.5]） | 0.5148 | 0.0601 | 0.026 | 未达预期 |
| CSP + LDA（crop [0,3]） | 0.4448 | 0.1089 | −0.101 | 更差，折间波动大 |
| bandpower+asymmetry + LDA | 0.5279 | 0.0691 | 0.069 | 加偏侧化特征无提升 |

**最终结果：被试内平衡准确率 0.5605（±0.0627），Cohen's κ = 0.124。**

按被试拆解（最终配置，within_subject）：

| 被试 | 平衡准确率 |
|---|---|
| 1 | 0.5083 |
| 2 | 0.5573 |
| 3 | 0.5833 |
| 4 | 0.5395 |
| 5 | 0.4911 |
| 6 | 0.6833 |

> 注：被试 5（0.49）低于随机，被试 6（0.68）显著高于随机，个体差异明显。

### 3.2 跨被试协议（cross_subject）

| 配置 | 平衡准确率（均值） | 标准差 | Cohen's κ |
|---|---|---|---|
| bandpower + LDA（最终配置） | 0.4585 | 0.0423 | −0.083 |
| CSP + LDA | 0.5138 | 0.0321 | 0.031 |

**跨被试结果：bandpower + LDA = 0.4585，低于随机（0.5）。**

这是 BCI 领域的已知现象：不做标定就套用到新使用者极难，小被试集上（n=6）
通常接近或低于随机。CSP 在跨被试协议下略好（0.5138），但仍基本无泛化能力。
该结果已如实报告，不隐藏。

## 4. 验证

### 4.1 置换检验（被试内协议）

- 方案：shuffle_control，3 批 × 10 次置换，合并共 30 次（seed = 0, 1, 2）
- 观测值：0.5605
- 打乱后分布：均值 0.489，标准差 0.0322，p95 = 0.5322，最大值 0.5411
- **p 值 = 0.0323 < 0.05，显著**

结论：观测值 0.5605 超过全部 30 次打乱结果中的最大值（0.5411），
p = 0.0323，**未发现流程泄漏迹象，结果在统计上显著**。

### 4.2 置换检验（单批验证）

每批独立 p = 0.0909（10 次置换理论下限），单批不足以达到 0.05 显著水平，
这是置换次数的固有限制，合并 30 次后 p = 0.0323 才达到显著。

## 6. 局限

1. **被试数 n = 6**：跨被试协议每折仅 1 名被试测试，结果方差大，接近随机水平
   是预期结果，不能据此判断方法无效。

2. **个体差异明显**：被试 5 的 within_subject 准确率（0.49）低于随机，
   被试 6（0.68）显著高于随机。总体均值被个体拖低，报告时应注明标准差。

3. **伪迹剔除改变了样本集**：agent 配置使用 251 段（剔除 19 段），
   基线使用 270 段，两组不完全可比较（`same_epoch_set = false`），
   增益部分来自样本集变化。

4. **CSP 未达到预期**：技能文档记录 CSP 可达 0.63，本数据上实测 0.51，
   未达预期。CSP 在 EEGMMIDB 被试 1–6 上效果不稳定的原因未知。

5. **未做独立留出被试**：本报告使用了置换检验（shuffle_control）而非
   留出被试（holdout_subject）验证。置换检验回答「是否泄漏」，
   留出被试回答「能否泛化到被试 7」，后者需额外数据。

6. **多重比较**：尝试了 5 组配置（bandpower、CSP、asymmetry、两个 crop 窗口），
   报告的是其中最佳结果，存在一定的选择偏差风险。置换检验在单一最终配置上
   执行，未对所有配置同时做多重比较校正。

7. **工具链测试**：本地 pytest 因 sklearn DLL 加载失败（`_sgd_fast.dll`）
   未能运行，三类测试（正常/边界/失败）均未执行。替代证据：所有分析步骤
   通过 MCP 工具完成，工具链本身正常；本地 Python 环境存在 DLL 兼容性问题。
