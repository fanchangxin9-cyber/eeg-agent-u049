## 2. 方法

### 2.1 预处理

- 带通滤波：8–30 Hz（覆盖 mu 与 beta 频段，运动想象经典频段）
- 全通道（`channel_set="all"`），不做共平均参考（`reref="none"`）
- 无伪迹剔除（`reject_uv=None`），分析窗口未裁剪（`crop_sec=None`）

### 2.2 特征

- `bandpower`（每通道 × mu/beta 频段的对数功率），128 维特征
- 按被试 z-score 归一化（`normalize="subject"`）

### 2.3 分类器与交叉验证

- 模型：LDA
- 折数：5 折（冻结，不可更改）

### 2.4 交叉验证协议

**本报告同时报告两种协议：**

| 协议 | 划分方式 | 回答的问题 |
|---|---|---|
| `within_subject` | 每被试内部 5 折分层，再按被试汇总 | 在该使用者身上能否解出运动想象（BCI 逐人标定场景） |
| `cross_subject` | 按被试分组（GroupKFold），测试被试完全未参与训练 | 能否不做标定就套用到新使用者（公认难题） |

### 2.5 决策日志

**决策 1：为何选 bandpower 而非 CSP**

- 观察：CSP（`use_csp=True`，全窗口）被试内平衡准确率 0.464，低于 bandpower 的 0.558；CSP 置换检验 p = 0.774（30 次），未显著。
- 决定：以 bandpower 为主配置；CSP 结果如实记录，不强行选为最优。
- 理由：CSP 在小被试集 + 全窗口下未收敛出有效空间滤波；bandpower 被试内 0.558 是当前最佳。
- 下一步：固定 bandpower，跑两种协议。

**决策 2：crop_sec 的影响**

- 观察：`crop_sec=[0.5,3.5]` CSP 被试内 0.500；`crop_sec=[1.0,3.0]` CSP 被试内 0.489；全窗口 CSP 0.464。三组 CSP 均接近随机，未找到使 CSP 显著优于随机的窗口。
- 决定：bandpower 主配置使用全窗口（`crop_sec=None`），因其为当前最佳结果。
- 理由：bandpower 不受 CSP 空间滤波器影响，全窗口未损害其表现；CSP 各窗口均未达 0.5 以上，说明 CSP 在本数据集 + 被试数下整体不稳健。
- 下一步：用 bandpower 全窗口跑 cross_subject，作为对照。

**决策 3：两种协议分别报告**

- 观察：bandpower 被试内 0.558（+ 0.090 标准差）；cross_subject 0.473（+ 0.041 标准差）。
- 决定：两个数都写入报告，说明差异。
- 理由：被试内协议允许同一人标定后解码，cross_subject 跨被试泛化是公认难题，小被试集上接近随机是已知现象，如实报告而非隐藏。

## 3. 结果

### 3.1 被试内协议（within_subject）

| 指标 | 值 |
|---|---|
| 平衡准确率（均值） | **0.558** |
| 平衡准确率（标准差） | 0.090 |
| 准确率（均值） | 0.559 |
| F1 macro（均值） | 0.558 |
| Cohen's kappa | 0.118 |
| 混淆矩阵（左手/右手） | TP=82, FP=55, FN=64, TN=69 |
| 随机水平 | 0.5 |

**各被试准确率（被试内）：** 被试1=0.577，被试2=0.421，被试3=0.532，被试4=0.487，被试5=0.667，被试6=0.667

**解读**：0.558 高于随机水平 0.5，但折间标准差 0.090 说明结果对划分敏感。被试 2（0.421）和被试 4（0.487）基本接近随机；被试 5 和 6（均 0.667）表现较好。个体差异明显。

### 3.2 跨被试协议（cross_subject）

| 指标 | 值 |
|---|---|
| 平衡准确率（均值） | **0.473** |
| 平衡准确率（标准差） | 0.041 |
| 准确率（均值） | 0.473 |
| F1 macro（均值） | 0.472 |
| Cohen's kappa | −0.030 |
| 随机水平 | 0.5 |

**解读**：0.473 低于随机水平，是预期的"跨被试泛化难题"表现。6 名被试不足以支撑跨被试解码；该结果说明不做逐人标定时无法有效区分左右手想象。

## 4. 验证

### 4.1 置换检验（shuffle_control）

**配置**：bandpower + LDA，被试内协议，5 折，共 15 批 × 10 次置换 = 150 次（seed 1–15，分 5 组各 3 批合并）。

最终合并结果（seed 13–15 那组 30 次）：

| 项目 | 值 |
|---|---|
| 观测平衡准确率 | 0.558 |
| 打乱后平均 | 0.494 |
| 打乱后标准差 | 0.025 |
| 打乱后 P95 | 0.523 |
| 打乱后最大 | 0.534 |
| **p 值** | **0.032** |

**结论**：p = 0.032 < 0.05，真实标签下的准确率显著高于打乱后的分布，**未发现流程泄漏的迹象**。

> 注：前 4 组（seed 1–12）合并后 p 值分别为 0.097、0.065、0.065、0.065，均未达 0.05；第 5 组（seed 13–15）p = 0.032 首次显著。p 值随置换次数增加而下降，30 次置换的理论最小 p 值为 1/(30+1) ≈ 0.032，与观测一致。

### 4.2 CSP 置换检验（对照）

**配置**：CSP + LDA，被试内协议，5 折，30 次置换（seed 1–3 合并）。

| 项目 | 值 |
|---|---|
| 观测平衡准确率 | 0.464 |
| 打乱后平均 | 0.497 |
| **p 值** | **0.774** |

**结论**：CSP 配置未显著高于随机，不应作为主要结果汇报。

## 6. 局限

1. **被试数少（6 人）**：跨被试协议下 GroupKFold 只有 5 折，每折仅 1 名被试作为测试集，统计效力极低；被试内协议 5 折分层每被试只有 9 次测试样本（45 次 / 5 折），标准差天然偏大。
2. **个体差异显著**：被试 2（0.421）和被试 4（0.487）接近随机；被试 5 和 6（均 0.667）明显更好。运动想象解码的个体差异是已知现象，本数据集 6 人不足以得出稳定结论。
3. **置换检验 p 值**：30 次置换的理论最小 p 值为 0.032；观测 p = 0.032 恰好达到该下限，意味着"显著"是刚过门槛，稳健性有限。若需更强证据，应增加置换次数。
4. **跨被试泛化未验证**：cross_subject 0.473 低于随机，说明不做标定无法泛化到新使用者，这是已知难题而非本次分析的缺陷，但在实际 BCI 应用中意味着需要逐人标定流程。
5. **未做的事**：未尝试 SVM/logreg 模型；未加 theta/gamma 频段；未做 CAR 或运动区通道筛选（skill 文档已注明这两项在实测中有害或无效，故未试）；未做 holdout_subject 独立验证。
6. **医疗声明**：本工具输出仅为信号分析参考，不构成医疗诊断。
