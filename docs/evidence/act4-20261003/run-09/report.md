# EEG 运动想象左右手解码分析报告

## 一、数据概况

- 数据集：EEGMMIDB v1.0.0（PhysioNet，ODC-BY 1.0）
- 被试：6 名（编号 1–6），每被试 45 试次，共 270 个事件段
- 通道：64 通道
- 任务：`left_vs_right_imagery`（想象左手 vs 想象右手）
- runs：[4, 8, 12]
- 采样率：160 Hz；加载窗口 [-0.2, 4.0] 秒
- 类别分布：左手 137 / 右手 133（基本平衡）
- 幅值：中位绝对值 22.0 µV，p99 167.0 µV，最大 639.0 µV（µV 级，量级正常）
- 诊断：无平坦通道、无 warnings，`healthy=true`
- raw handle：`raw_f89733bb9c7d`

## 二、方法

### 2.1 预处理

8–30 Hz 带通（mu + beta），**不加 CAR**（skill 实测 CAR 在 CSP 流程下有害：0.552→0.528），**不做运动区选道**（CSP 自身是空间滤波器，手动筛通道多余，实测 0.552→0.551）。伪迹剔除 `reject_uv=150`。

分析窗口先后试了 `[0.5,3.5]`、`[0.5,2.5]`、`[0.5,2.0]` 三组，最终选定 `[0.5,3.5]`（CSP 下最高）。

### 2.2 特征与模型

先后试了：

1. **bandpower（mu/beta）+ 按被试 z-score 归一化 + LDA**：within_subject 平衡准确率 0.4331（±0.0686），kappa -0.1391，**低于随机 0.5**。
2. **CSP + LDA**（对 clean 产物直接做空间滤波）：within_subject 平衡准确率 **0.4875**（±0.089），kappa -0.0205。
3. CSP + 窗口 `[0.5,2.5]`：0.4866（±0.0506），略低于 2。
4. CSP + 窗口 `[0.5,2.0]`：0.4380（±0.083），进一步变差。

**最终选定：配置 2（CSP + LDA，窗口 `[0.5,3.5]`）**。

### 2.3 交叉验证协议

按 skill 要求，**两种协议都跑并分别报告**：

- `within_subject`：每个被试内部 5 折分层，再按被试汇总。衡量"在该使用者身上能否解出运动想象"，对应真实 BCI 的逐人标定流程。
- `cross_subject`：GroupKFold(5) 按被试分组，测试被试完全不参与训练。衡量"能否不做标定就套用到新使用者"，公认难题，小被试集上通常接近随机。

### 2.4 决策日志摘要

- **观察 1**：bandpower + LDA within_subject = 0.4331，低于随机。
  **决定**：不动滤波带宽，直接上 CSP（skill 实测最大增益方向）。
  **理由**：运动想象判别信息藏在 C3/C4 一带 mu/beta 对侧 ERD，CSP 数据驱动学空间权重，比手算功率强。
  **下一步**：`eeg_evaluate(clean, use_csp=True, within_subject)`。

- **观察 2**：CSP within_subject = 0.4875，仍低于随机。
  **决定**：试窗口收窄 `[0.5,2.5]`。
  **理由**：ERD/ERS 集中在提示后 0.5–3s，尾段静息噪声稀释 CSP 权重。
  **下一步**：新预处理 → CSP 评估。

- **观察 3**：窗口 `[0.5,2.5]` = 0.4866（略降），窗口 `[0.5,2.0]` = 0.4380（明显降）。
  **决定**：按停止准则（连续 2 组窗口变体无 >1pp 提升）停在配置 2。
  **理由**：当前数据与配置下未能有效区分，如实报告，不再堆配置蒙高值。

## 三、结果

### 3.1 主结果（within_subject 协议，CSP + LDA）

- **平衡准确率：0.4875（±0.089）**
- 准确率：0.4900
- F1（macro）：0.4896
- Cohen's kappa：-0.0205
- 混淆矩阵：[[65, 62], [66, 58]]
- 逐被试：1→0.5369，2→0.5781，3→0.5821，4→0.4526，5→0.4464，6→0.3292
- 随机水平：0.5

**结论：within_subject 协议下平衡准确率 0.4875，低于随机水平 0.5，CSP 未能有效区分左右手想象。**

### 3.2 跨被试协议（cross_subject，同一 clean 产物 + CSP + LDA）

- **平衡准确率：0.5143（±0.0197）**
- 准确率：0.5025
- F1（macro）：0.4045
- Cohen's kappa：0.0034
- 混淆矩阵：[[67, 60], [65, 59]]
- 逐被试（holdout）：1→0.5122，2→0.5111，3→0.4878，4→0.5143，5→0.4667，6→0.5227

**结论：cross_subject 协议下 0.5143，基本等于随机水平 0.5。比 within_subject 略高 2.7pp 是 6 被试 × 5 折的统计噪声，不构成泛化证据。**

### 3.3 两种协议的差异说明

within_subject（0.4875）与 cross_subject（0.5143）的差异 2.68pp 在两组标准差（0.089 / 0.0197）之内，无实际意义。两者都远低于 1.0，都未通过随机水平检验。差异原因是：within_subject 的训练/测试来自同一人（标准 BCI 标定场景），cross_subject 的训练/测试来自不同人（无标定泛化场景），后者受个体间神经解剖差异影响更大，小被试集上接近随机是已知现象。

## 四、验证

### 4.1 置换检验（within_subject，CSP 最优配置）

按 skill 的分批合并办法：分 3 批各 10 次置换，seed=1/2/3，模型/协议/折数一致（CSP+LDA，5 折，within_subject），再合并。

- 单批结果：
  - seed=1：打乱均值 0.4923，max 0.5324，p=0.6364
  - seed=2：打乱均值 0.4865，max 0.5615，p=0.4545
  - seed=3：打乱均值 0.4887，max 0.5672，p=0.4545
- **合并 30 次置换**：打乱均值 0.4892（±0.0371），p95=0.5542，max=0.5672
- **观测值 0.4875，p=0.4839**

**p 值理论下限 1/31≈0.032，观测值落在打乱分布中部（甚至略低于打乱均值 0.4892），p=0.4839 远大于 0.05。结果不是"次数不够漏检"，而是"效应本身不存在"——打乱标签后的分布与真实标签下的观测值无法区分。**

### 4.2 置换检验（cross_subject）

同样 3 批各 10 次，seed=1/2/3 合并：

- 单批 p：0.1818 / 0.0909 / 0.3636
- **合并 30 次**：打乱均值 0.4959（±0.019），max 0.5326
- **观测值 0.5143，p=0.1613**

**cross_subject 同样未达显著（p=0.1613 > 0.05）。**

### 4.3 留出被试验证

`holdout_subject`，test_subjects=[4,5,6]，train_subjects=[1,2,3]，CSP+LDA：

- 平衡准确率：0.4876（测试集 124 个事件段）
- kappa：-0.0245
- 混淆矩阵：[[16, 47], [17, 44]]

**留出被试（完全未参与任何拟合步骤含标准化）的平衡准确率 0.4876，仍低于随机 0.5，与 cross_subject 结果一致——独立验证指向同一结论：没有可泛化的判别信息。**

## 五、与基线对比

冻结基线：`baseline_bandpower_lda`（8–30 Hz，窗口 [0.5,3.5]，**不带伪迹剔除**，bandpower mu/beta + 按被试 z-score + LDA，within_subject 5 折，n_epochs=270）。

- 基线平衡准确率：0.3952（±0.0776）
- 本配置平衡准确率：0.4875（±0.089）
- **delta = +0.0923**
- **verdict = agent_config_better**（服务端计算）

**增益来源说明**：本配置比基线多了两个变化——(1) `reject_uv=150` 伪迹剔除（n_epochs 从 270 减到 251，剔除 19 个试次），(2) CSP 替代 bandpower。服务端 fairness 标注 `same_epoch_set=false`，说明差异中同时包含"剔除伪迹试次"的贡献，**不是纯 CSP 增益**。delta 0.0923 是"预处理决策 + CSP"的复合效果。

## 六、局限

1. **被试数少（n=6）**：within_subject 每被试内部 5 折，cross_subject 每折只有 1 个被试做 holdout，方差大（within_subject 标准差 0.089），结论的统计功效有限。
2. **个体差异大**：within_subject 逐被试准确率从 0.3292（被试 6）到 0.5821（被试 3）波动近 25pp，说明运动想象信号强度因人而异，部分被试可能天生 ERD 弱或想象策略不佳。
3. **跨被试泛化接近随机**：cross_subject 0.5143 与随机水平 0.5 无差异，这是公认难题（小被试集上个体神经解剖差异主导），不是本分析的失败——如实报告。
4. **未做的事**：
   - 未试 SVM / logreg 模型（只试了 LDA）
   - 未试 `bandpower+asymmetry` 特征（C3/C4 左右差值）
   - 未试加 theta 频段（skill 实测在 6 被试时反而变差，跳过）
   - 未试 CAR（skill 实测有害，跳过）
   - 未试运动区选道（skill 实测无变化，跳过）
   - 未试更多被试（数据只有 6 名）
   - 未做时间-频域联合特征（如 CSP + bandpower 拼接）
5. **多重比较**：试了 4 组 within_subject 配置（bandpower/CSP/CSP+窗口2.5/CSP+窗口2.0），未做 Bonferroni 校正。由于最终配置是**按预设停止准则选定**（而非从 4 组里挑最高的），多重比较的偏差有限，但 4 组中最高的 0.4875 仍远低于随机 0.5，所以"挑最高的"这个动作本身不影响"未通过随机检验"的结论。
6. **非医疗诊断**：本报告仅为信号分析参考，不构成任何医疗建议或诊断。
7. **置换检验 p 值下限**：30 次置换的 p 值理论下限是 1/31≈0.032。本次 within_subject p=0.4839、cross_subject p=0.1613，都远大于 0.05，结论"未达显著"是稳健的，不受次数限制影响。
