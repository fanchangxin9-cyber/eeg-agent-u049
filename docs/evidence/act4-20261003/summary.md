## 3. 与第三幕对照

| | 第三幕（`eeg_trial_run` 模拟器） | 第四幕（agent 本体） |
|---|---|---|
| 被测对象 | 程序化搜索模拟器 | agent 本体（实跑 P1） |
| 搜索规模 | 固定 budget 1 / 4 / 24 | agent 自己决定（实测 6–9 个配置） |
| 评估协议 | **固定** within_subject | agent 自选（宽口径里 run-06 用了 cross_subject） |
| 虚报率 | 0.10 / 0.20 / 0.525 | 宽 0.20 · 严 0.10 · 净结论 0.20 |

**只有严口径能与第三幕并排**（协议相同）。而两层的**行动自由度不同**——模拟器固定
配置数与协议，agent 还会自选评估协议与置换次数。所以「模拟器预测了 agent」
这个说法**不成立**。
