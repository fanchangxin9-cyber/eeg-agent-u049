# EEG 运动想象解码分析报告

## 1. 数据概况

- 数据集：EEGMMIDB v1.0.0（PhysioNet，ODC-BY 1.0），raw handle `raw_eb4167a8f5ef`
- 被试：1–6 共 6 名；运行 4/8/12；任务 `left_vs_right_imagery`（左手 vs 右手想象）
- 每被试 45 段，共 270 段；类别分布 左手 137 / 右手 133（基本平衡）
- 64 通道，采样率 160 Hz，加载窗口 [-0.2, 4.0] 秒
- 质量诊断（eeg_inspect）：无警告；无平坦通道；幅值中位 22 µV、p99 167 µV、最大 639 µV（存在少量高幅伪迹）

## 2. 方法

**最终主配置**：带通 8–30 Hz + 50 Hz 工频陷波 + 分析窗口 [0.5, 3.5] s + 全通道 + 原始参考 + **CSP 特征 + LDA 分类**，5 折交叉验证。

决策轨迹（每轮：观察 → 决定 → 理由 → 下一步）：

1. **诊断驱动预处理**：诊断无警告、类别平衡，故不剔被试不剔通道；p99=167 µV 提示尾部大伪迹，先试 `reject_uv=100`，结果剔除 54% 样本（被试 1/3/4 剔除比例 0.844/0.911/1.0）→ 判定阈值过严，放宽回不剔除（`reject_uv=null`），保留全部 270 段。
2. **bandpower 基线**（mu+beta，按被试 z-score，被试内 5 折）：0.466，接近随机且低于 0.5 → 决定换 CSP。理由：CSP 是空间滤波器，实测对 mu/beta 解调信息更敏感（搜索空间重心）。
3. **CSP [0.5, 3.5]**：0.496，相对 bandpower +3.0 个百分点 → 当前最佳。
4. **CSP [0.3, 2.5]**：0.481，反而变差 → 窗口前移无增益。
5. **bandpower+asymmetry [0.5, 3.5]**：0.469，也不如纯 bandpower → 对称差值特征在这批被试上未带来收益。
6. 触发停止准则（最多 6 组配置；后 3 组相对最佳无 ≥1 个百分点提升）→ 停止遍历，锁定 CSP [0.5,3.5] 为主配置。

**交叉验证协议**：
- 被试内（within_subject，每被试内部 5 折分层）：回答"在固定使用者上能否解出"——对应真实 BCI 逐人标定流程，作为主结果。
- 跨被试（cross_subject，GroupKFold(5) 按被试分组）：回答"能否免标定套用到新使用者"——已知难题，同样跑了一遍如实报告。

## 3. 结果

| 配置 | 协议 | 平衡准确率 | std | kappa |
|---|---|---|---|---|
| CSP + LDA, 窗口 [0.5,3.5] | 被试内 | 0.4964 | 0.1147 | -0.0083 |
| CSP + LDA, 窗口 [0.5,3.5] | 跨被试 | 0.5045 | 0.0058 | 0.0051 |
| CSP + LDA, 窗口 [0.3,2.5] | 被试内 | 0.4814 | 0.0997 | -0.0364 |
| bandpower + LDA | 被试内 | 0.4661 | 0.0959 | -0.0667 |
| bandpower+asymmetry + LDA | 被试内 | 0.4685 | 0.1133 | -0.0596 |
| bandpower+asymmetry + LDA | 跨被试 | 0.4966 | 0.0608 | 0.0001 |

混淆矩阵（被试内 CSP [0.5,3.5]）：左手真值 137 段中 72 判对 / 65 判错；右手 133 段中 62 判对 / 71 判错。

被试内各被试折间平衡准确率：0.3775 / 0.3547 / 0.6670 / 0.5998 / 0.5387 / 0.4405（std 0.1147），个体差异主导结果。跨被试各被试在 0.4667–0.5333 之间（std 0.0199），均≈随机。

**结论：本批被试下，左右手运动想象未能达到统计显著的可区分。**

## 4. 验证

- **置换检验**（shuffle_control，被试内协议，与主评估一致）：3 批 × 10 次（seed=1/2/3，模型/协议/折数一致）合并为 30 次。观察值 0.4964 vs 空分布均值 0.5101（std 0.0411，p95 0.5638），**p = 0.7097，远未显著**（30 次置换的 p 下限为 0.0323，次数足够，不显著是真实结论而非检验力不足）。
- **留出被试**（holdout_subject，被试 6 完全不参与训练，含标准化）：平衡准确率 0.5268，kappa 0.0517，45 段测试中 23 判对。
- **结论**：被试内结果与打乱标签分布不可区分，不存在流程泄漏可以解释的"虚假增益"——但也不存在可声称的真实效应；这与第 3 节的结论一致。

## 5. 与冻结基线对比

服务端 `eeg_ablation` 计算结果：
- 基线（bandpower + LDA，被试内 5 折，同 raw、同划分）：0.4661 ± 0.0959
- Agent 配置（CSP + LDA）：0.4964 ± 0.1147
- **delta = +0.0303，verdict = agent_config_better**（由服务端判定，非自行宣称）

增益来源：CSP 空间滤波把 mu/beta 时变对侧抑制的信息加权提取出来，而非改变预处理（两组 fair 对照 `same_epoch_set=true`，唯一差异是特征方案 CSP vs bandpower）。注意：增益是在"低于随机"的基线上取得的 +3 个百分点，不能解读为绝对能力，两组都未达显著。

## 6. 局限

1. **被试数仅 6 人**，被试内 5 折的跨被试外推力有限；跨被试协议下 GroupKFold(5) 的每折只有 54 段训练样本，指标接近随机是已知现象而非模型失败。
2. **个体差异极大**：被试内 std 0.1147，单被试折值在 0.35–0.67 之间；被试 4、5 接近随机，被试 3 最好，均值掩盖了这种异质性。
3. **多重比较**：本次遍历了 6 组配置，报告的是探索中挑选的最佳配置；置换检验针对该单一配置做（p=0.7097），未对"多组中取最大值"这一挑选行为本身做校正。
4. **未做的事**：未做 CAR/选道对照（文献实测二者在本数据上无效/有害，未重复验证）；未试 SVM/logreg 分类器；未做逐被试诊断性分析（例如单独排除被试 4/5 再评估）。
5. 输出仅为信号分析参考，不构成医疗诊断。

*本报告所有数字均来自 eeg_evidence 返回的 claims（C1–Cn），评估协议已逐项标明。*
