# EEG 运动想象解码分析报告

## 1. 数据概况

- **数据集**：EEGMMIDB v1.0.0（PhysioNet，ODC-BY 1.0）
- **被试**：6 名（编号 1–6）
- **Run**：4、8、12
- **任务**：想象左手 vs 想象右手（left vs right fist imagery）
- **原始事件段数**：270（每名被试 45 段）
- **通道数**：64
- **采样率**：160 Hz
- **类别分布**：left_fist 137 / right_fist 133（基本平衡）

## 2. 方法

### 2.1 预处理

- **带通**：8–30 Hz（覆盖 mu 8–13 Hz 与 beta 13–30 Hz，运动想象经典频带）
- **陷波**：未加（数据无工频伪迹迹象）
- **伪迹剔除**：reject_uv = 150 μV；最终 best 配置（crop [1.0, 3.0]）剔除 15/270 = 5.6%
- **通道选择**：all（64 通道全保留）
- **参考**：none（共平均参考实测有害，未使用）
- **分析窗口**：crop_sec = [1.0, 3.0]（迭代后选定，见 2.2）

### 2.2 为什么这样选（决策日志摘要）

| 轮次 | 观察 | 决定 | 理由 |
|---|---|---|---|
| 1 | bandpower within=0.522，CSP 全窗口 within=0.490 | 换窗口 | 全窗口含静息段噪声，判别信息集中在提示后 |
| 2 | CSP crop[0.5,3.5] within=0.515 | 前移且收窄到 [1.0,3.0] | 聚焦 ERD 高峰期 |
| 3 | CSP crop[1.0,3.0] within=0.553（最佳） | 停止迭代 | 超过停止准则阈值，不再穷举 |

### 2.3 特征与模型

- **特征**：CSP（Common Spatial Patterns）+ LDA
- **交叉验证**：5 折
- **两种协议均跑**：
  - `within_subject`：每被试内部按试次 5 折分层（BCI 逐人标定场景）
  - `cross_subject`：GroupKFold 按被试分组，测试被试不参与训练

## 3. 结果

### 3.1 最佳配置（CSP + LDA，crop [1.0, 3.0]，reject_uv=150）

| 指标 | within_subject | cross_subject |
|---|---|---|
| 平衡准确率（mean） | **0.5527** | **0.4621** |
| 平衡准确率（std） | 0.1217 | 0.0342 |
| 准确率（mean） | 0.5569 | 0.4642 |
| F1 macro | 0.5568 | 0.3839 |
| Cohen's kappa | 0.1135 | -0.0688 |
| 混淆矩阵 | [[73, 56], [57, 69]] | [[71, 58], [78, 48]] |
| 逐被试准确率 | 1:0.5095 2:0.4437 3:0.6159 4:0.3694 5:0.6726 6:0.7050 | 1:0.4878 2:0.4222 3:0.4286 4:0.4737 5:0.4667 6:0.5227 |

- **within_subject**：平衡准确率 0.553 高于随机 0.5，被试 5、6 表现好（>0.67），被试 4 偏低（0.369）。
- **cross_subject**：平衡准确率 0.462 低于随机 0.5，说明不标定直接套用新被试基本不可行（公认难题）。

## 4. 验证

### 4.1 置换检验（within_subject，CSP crop[1.0,3.0]）

- **方法**：3 批 × 10 次 = 共 30 次标签打乱（seed 1/2/3），合并后计算 p 值
- **观测平衡准确率**：0.5527
- **空分布均值**：0.4949，std = 0.0419，p95 = 0.5771，max = 0.6107
- **p 值**：0.1290
- **结论**：30 次置换后 p = 0.129，**未达 0.05 显著水平**。观测值（0.553）虽高于空分布均值（0.495），但落在 p95（0.577）以下，尚不能排除是流程泄漏或随机波动。

### 4.2 置换检验（cross_subject，CSP crop[1.0,3.0]）

- 10 次置换，p = 1.0000，观测 0.4621 远低于空分布 max（0.544）
- 该配置在 cross_subject 下**无显著判别力**，与 3.1 结果一致

### 4.3 说明

置换检验未能确认 within_subject 的 0.553 显著高于随机。这是小被试集（6 人）+ 高折间方差（std 0.122）下的统计功效不足，不代表效果不存在，但也不能宣称"显著"。

## 5. 与冻结基线对比

- **基线配置**：bandpower（mu+beta）+ LDA，crop [0.5, 3.5]，reject_uv=None，within_subject，5 折
- **基线平衡准确率**：0.5187（std 0.0815）
- **Agent 配置**：CSP + LDA，crop [1.0, 3.0]，reject_uv=150，within_subject，5 折
- **Agent 平衡准确率**：0.5527（std 0.1217）
- **delta**：+0.0340
- **verdict**（服务端计算）：**agent_config_better**

增益来源：CSP 空间滤波 + 收窄分析窗口 + 伪迹剔除，三项叠加贡献。

## 6. 局限

1. **被试数**：仅 6 名被试，统计功效低，30 次置换 p 值下限为 1/31 ≈ 0.032，但仍未达标。
2. **个体差异大**：被试内标准差 0.122，被试 4 准确率仅 0.369（低于随机），拉低了整体均值。
3. **cross_subject 基本不可用**：0.462 低于随机，证实不做逐人标定时模型无法泛化到新使用者（已知难题）。
4. **置换检验不显著**：p = 0.129，不足以排除流程泄漏，结果应视为"提示性"而非"确证性"。
5. **未做消融**：未单独量化 CSP 贡献与窗口贡献各自的份额。
6. **未跑更多被试/run**：EEGMMIDB 还有更多被试可用，未纳入。
