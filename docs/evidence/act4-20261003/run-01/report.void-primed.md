# EEG 运动想象解码分析报告（run-01）

## 1. 数据概况

- **数据集**：EEGMMIDB v1.0.0（PhysioNet，ODC-BY 1.0）
- **任务**：左手 vs 右手想象（`left_vs_right_imagery`）
- **被试**：6 名（编号 1–6），各 45 段事件
- **总样本**：270 段事件（左 137 / 右 133，基本平衡）
- **通道数**：64 通道，采样率 160 Hz，加载窗口 [-0.2, 4.0] s
- **质量诊断**：健康，无平坦通道，无警告；中位幅值 22 µV、p99 = 167 µV，需做伪迹剔除

## 2. 方法

**最终配置**（由搜索过程锁定）：
- 预处理：8–30 Hz 带通，无陷波，分析窗口 `crop_sec = [0.5, 3.5]`，伪迹阈值 `reject_uv = 200`（剔除 3/270 = 1.1%，各被试 0–4.4%），全通道，原始参考
- 特征：`bandpower`（mu + beta 频段），按被试 z-score 归一化
- 模型：LDA，5 折交叉验证
- **协议**：`within_subject`（每被试内部 5 折分层，再按被试汇总）

**为什么这样选**（决策日志摘要）：

1. 观察诊断显示数据健康但 p99/max 偏大 → 决定加 `reject_uv=200` 剔除伪迹 → 结果只剔 1.1% 样本，安全
2. 跑默认 bandpower+LDA（0.5505）后试 CSP（0.479）与 CSP+窄窗口（0.492），两次都**低于**随机水平 0.5，与参考表"CSP 最优"方向相反 → 说明 CSP 在这份数据/样本量下没有优势，停止进一步调 CSP，锁定 bandpower 方案
3. 试 `bandpower+asymmetry`（0.5104），也低于 bandpower → 锁定 `bandpower` 特征
4. 同步跑跨被试协议（0.498）作为对照

**关于协议**：`within_subject` 衡量"在该使用者身上逐人标定后能否解出运动想象"，是本分析的主指标。`cross_subject`（0.498）衡量"不标定直接套用到新被试"，已知在 6 被试小样本下接近随机，两者都如实报告。

## 3. 结果

### 被试内（within_subject，主结果）
| 指标 | 数值 |
|---|---|
| 平衡准确率 | **0.5505** |
| 标准差 | 0.0495 |
| 准确率 | 0.5506 |
| F1（macro） | 0.5505 |
| Cohen's κ | 0.101 |
| 混淆矩阵 | [[75, 60], [60, 72]] |
| 各被试 | 0.500 / 0.557 / 0.555 / 0.556 / 0.491 / 0.643 |

### 跨被试（cross_subject，对照）
| 指标 | 数值 |
|---|---|
| 平衡准确率 | 0.498 |
| 标准差 | 0.0516 |
| Cohen's κ | -0.0111 |
| 混淆矩阵 | [[66, 69], [66, 66]] |

**差异原因**：跨被试协议下各被试的 mu/beta 功率基线差异极大，z-score 归一化是各自内部的，跨人时不可比；6 被试的小样本也让训练集无法覆盖新被试的个体特征，结果落到随机水平附近是文献已知现象，不是方法失误。

## 4. 验证

对主结果做置换检验：
- **单批 30 次**（seed=1）：p = 0.0323，观测值超过全部打乱结果（打乱 max 0.5435）
- **单批 30 次**（seed=2）：p = 0.0968，打乱 max 0.5707 超过观测值
- **合并 60 次**（`shuffle_control_combine`，两批协议/折数/模型一致）：p = **0.0492**，打乱均值 0.497、p95 = 0.5438、max = 0.5707

结论：60 次合并置换下 p = 0.0492，略低于 0.05 阈值；真实标签下 0.5505 显著高于打乱后的均值 0.497。**未发现流程泄漏迹象**，结果不是标签顺序造成的假象。两批单跑时结论不一致（一个显著、一个不显著），也提示 30 次置换对单点结论的敏感性较高——这是 p 值下限 1/(n+1) 机制的直接体现。

## 6. 局限

- **被试数 6**：跨被试协议下训练/测试被试划分后每折样本量小，结果对随机划分高度敏感（std 0.05+）
- **个体差异大**：被试 6 达到 0.643，被试 1/5 约 0.5，聚合均值掩盖了个体间的巨大方差
- **CSP 未发挥预期作用**：参考实验"CSP 0.55→0.63"在本数据上没有复现，两次尝试都低于随机水平，未能解释原因，也不应据此宣称 CSP 对本数据无效
- **置换检验的有限精度**：60 次置换 p 下限为 1/61≈0.0164，当前 p=0.0492 落在不显著与显著交界处，结论对置换次数敏感
- **未做的事**：未做 holdout_subject 验证；未尝试更严的 `reject_uv` 对照；未做统计多重比较校正
