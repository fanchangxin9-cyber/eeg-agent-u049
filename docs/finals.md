## 问答准备

决赛须「说明作品的关键实现及验证方法」。预判几个问题：

- **这和写个 for 循环遍历参数有什么区别？**
  答：决策依据是每个被试的诊断文本（平坦通道、事件丢失、样本量差异），
  策略随数据变化；且有失败恢复与证据绑定。准备好展示决策日志的具体条目。

- **准确率为什么不是更高？**
  答：如实说明。运动想象的公开基线本就在这个区间；个体差异大是已知现象；
  我们报告的是按被试分组的严格划分结果，不是被试内划分的乐观数字。
  **不要**为了好看换成被试内划分。

- **怎么证明不是数据泄漏？**
  答：置换检验 + 留出被试，两个都做了。

- **Agnes 模型在其中的作用是什么？**
  答：任务规划、诊断解读、配置决策、指标解释、报告生成与证据绑定。
  说明工具是执行层，决策层在 AGH。
