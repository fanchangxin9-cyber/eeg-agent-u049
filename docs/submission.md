## 完整性自检（提交前最后一遍）

对照指南 §13「不进入评审或取消资格的情形」逐条自查：

- [ ] 有可运行作品，不是只有 PPT / 概念说明 / 界面原型
- [ ] AGH 承担了**核心任务流程**，不是只做外围辅助或生成说明文字
- [ ] 作品不是普通聊天问答，确实调用了数据与工具
- [ ] 能提供执行记录、测试材料、可复现运行说明
- [ ] 作品由团队成员独立完成，无教师或校外人员代做
- [ ] **没有伪造实验数据、运行记录或仿真结果**
- [ ] 如实说明了全部第三方代码、数据、素材的来源

> 最后一条是硬红线。本仓库的历史版本中 `docs/agh_setup.md` 与
> `docs/demo_script.md` 曾出现未经验证的具体指标，已在重构中全部移除。
> 提交前请再全文检索一遍，确认没有任何"看起来像真实结果但实际没跑过"的数字。
